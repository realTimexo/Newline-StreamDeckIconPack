# Stream Deck Icon Pack (144×144)

300 icons for the Elgato Stream Deck, featuring white outline symbols with rounded, thick lines.

Each icon comes in two variants (600 PNG files in total):

- `dark/` – White symbol on a black background (default)
- `light/` – Black symbol on a white background (highlight / active state)

All files are **144×144 px** and named `dark_<category>_<name>.png` or `light_<category>_<name>.png`, for example `dark_tools_cloud_drive.png` and `light_tools_cloud_drive.png`.

Examples include mic mute/unmute, recording on/off/pause, headphones on/off, speaker volume up/down/mute, scene switching, going live, Twitch ads, clapperboard, notification bell on/off, Wi-Fi, restart, settings, ban hammer, captions, and much more.

The `brands/` folder also contains game, emulator, and software logos (e.g. Blender, CapCut, Cemu, Citra, Dolphin Emulator, Epic Games, and more) that have been adapted to match the pack's style using original files provided by the repository owner.

## How to Use

1. Open the Stream Deck software and select a button.
2. Click the image field → *Choose Image* → select the desired PNG from `dark/` or `light/`.
3. For on/off buttons (Multi Actions or state-based buttons), use the `dark_` version as the default state and the `light_` version as the active state.
